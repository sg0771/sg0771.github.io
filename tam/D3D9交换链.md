如何使用 IDirect3DSwapChain9

将ffmpeg DXVA2硬解码的 AVFrame 里面的D3DSurface 显示到其它窗口

要将 FFmpeg DXVA2 硬解码出来的 IDirect3DSurface9 渲染到另一个独立的窗口，核心逻辑在于管理 Direct3D9 设备的隐式交换链（Implicit SwapChain）或为新窗口创建额外的附加交换链（Additional SwapChain）。

DXVA2 解码通常会绑定一个特定的 D3D9 设备，而 D3D9 允许通过创建额外的 IDirect3DSwapChain9 来让同一个设备驱动多个不同的窗口（HWND）。

下面是实现这一功能的核心步骤和完整 C++ 代码逻辑。

核心实现步骤
获取 DXVA2 的 D3D 设备：从 FFmpeg 解码上下文或配置的 AVHWDeviceContext 中拿到 DXVA2 正在使用的 IDirect3DDevice9。

创建附加交换链：调用 IDirect3DDevice9::CreateAdditionalSwapChain，将目标窗口的 HWND 传入 D3DPRESENT_PARAMETERS。

获取后备缓冲区（Back Buffer）：从新创建的 SwapChain 中获取 Surface。

表面拷贝（StretchRect）：由于 DXVA2 解码出的 Surface 通常是 NV12 或 YV12 格式，且带有 D3DUSAGE_RENDERTARGET 标志，不能直接 Present，需要使用 IDirect3DDevice9::StretchRect 将其拷贝（并自动色彩空间转换）到 SwapChain 的 RGB 后备缓冲区。

提交显示：调用 SwapChain 的 Present 方法将画面渲染到目标窗口。

C++ 代码实现
以下是封装好的核心渲染逻辑：

C++
#pragma comment(lib, "d3d9.lib")
#include <d3d9.h>

// 假设这些是 FFmpeg 解码库的头文件
extern "C" {
#include <libavutil/hwcontext_dxva2.h>
#include <libavutil/frame.h>
}

class DXVA2WindowRenderer {
private:
    IDirect3DDevice9*          m_pDevice = nullptr;
    IDirect3DSwapChain9*     m_pSwapChain = nullptr;
    HWND                       m_targetHwnd = 0;
    UINT                       m_width = 0;
    UINT                       m_height = 0;

public:
    DXVA2WindowRenderer(IDirect3DDevice9* pDevice, HWND targetHwnd)
        : m_pDevice(pDevice), m_targetHwnd(targetHwnd) {
        if (m_pDevice) m_pDevice->AddRef();
    }

    ~DXVA2WindowRenderer() {
        ReleaseSwapChain();
        if (m_pDevice) m_pDevice->Release();
    }

    void ReleaseSwapChain() {
        if (m_pSwapChain) {
            m_pSwapChain->Release();
            m_pSwapChain = nullptr;
        }
    }

    // 根据解码帧的宽高，动态创建或重置 SwapChain
    bool InitSwapChain(UINT width, UINT height) {
        if (m_pSwapChain && m_width == width && m_height == height) {
            return true; // 尺寸未变，复用现有的 SwapChain
        }

        ReleaseSwapChain();

        D3DPRESENT_PARAMETERS d3dpp = {};
        d3dpp.Windowed = TRUE;
        d3dpp.hDeviceWindow = m_targetHwnd; // 绑定目标渲染窗口
        d3dpp.BackBufferWidth = width;
        d3dpp.BackBufferHeight = height;
        d3dpp.BackBufferFormat = D3DFMT_X8R8G8B8; // 常见的RGB后备缓冲格式
        d3dpp.BackBufferCount = 1;
        d3dpp.SwapEffect = D3DSWAPEFFECT_DISCARD;
        d3dpp.Flags = D3DPRESENTFLAG_VIDEO;
        d3dpp.PresentationInterval = D3DPRESENT_INTERVAL_IMMEDIATE;

        HRESULT hr = m_pDevice->CreateAdditionalSwapChain(&d3dpp, &m_pSwapChain);
        if (FAILED(hr)) {
            return false;
        }

        m_width = width;
        m_height = height;
        return true;
    }

    bool RenderFrame(AVFrame* pFrame) {
        if (!pFrame || pFrame->format != AV_PIX_FMT_DXVA2_VLD) {
            return false;
        }

        // 1. 从 AVFrame 中提取 DXVA2 Surface 指针
        IDirect3DSurface9* pDecSurface = (IDirect3DSurface9*)pFrame->data[3];
        if (!pDecSurface) return false;

        // 2. 确保 SwapChain 已经初始化，且分辨率匹配
        if (!InitSwapChain(pFrame->width, pFrame->height)) {
            return false;
        }

        // 3. 获取 SwapChain 的 BackBuffer Surface
        IDirect3DSurface9* pBackBuffer = nullptr;
        HRESULT hr = m_pSwapChain->GetBackBuffer(0, D3DBACKBUFFER_TYPE_MONO, &pBackBuffer);
        if (FAILED(hr)) return false;

        // 4. 将 NV12/YV12 的解码表面拷贝到 RGB 的后备缓冲区
        // StretchRect 在硬件支持时会自动处理颜色空间转换 (YUV -> RGB)
        hr = m_pDevice->StretchRect(pDecSurface, nullptr, pBackBuffer, nullptr, D3DTEXF_NONE);
        
        // 释放 BackBuffer 引用计数
        pBackBuffer->Release();

        if (FAILED(hr)) {
            return false;
        }

        // 5. 提交到目标窗口显示
        hr = m_pSwapChain->Present(nullptr, nullptr, m_targetHwnd, nullptr, 0);
        return SUCCEEDED(hr);
    }
};
关键技术细节与坑点
1. 如何从 FFmpeg 获取 IDirect3DDevice9？
在 FFmpeg 初始化 DXVA2 的阶段，你需要自行创建 D3D9 设备并填充到 AVHWDeviceContext。可以在解码循环外部通过如下方式拿到当前解码器绑定的设备指针：

C++
AVHWDeviceContext* hw_device_ctx = (AVHWDeviceContext*)pCodecCtx->hw_device_ctx->data;
if (hw_device_ctx && hw_device_ctx->type == AV_HWDEVICE_TYPE_DXVA2) {
    AVDXVA2DeviceContext* dxva2_ctx = (AVDXVA2DeviceContext*)hw_device_ctx->hwctx;
    IDirect3DDevice9* pDevice = dxva2_ctx->devmgr; // 注意：FFmpeg 内部通常维护的是 IDirect3DDeviceManager9 或直接是设备
    // 如果是 AVDXVA2DeviceContext，它内部拥有的是 IDirect3DDeviceManager9*
    // 可以通过 D3D9的 GetVideoDecoderDeviceManager 拿到 Device
}
注：最稳妥的方式是在你自己初始化 FFmpeg DXVA2 硬件上下文时，就把你创建的 IDirect3DDevice9 保存一份供渲染器使用。*

2. 多线程与多窗口（Multi-threading & Device Lost）
同一设备跨窗口：使用 CreateAdditionalSwapChain 是最高效的方案，因为它不需要你为第二个窗口重新初始化完整的 D3D9 设备，从而避免了跨设备传输显存数据的昂贵开销。

StretchRect 的限制：StretchRect 要求源 Surface（AVFrame）和目标 Surface（BackBuffer）属于同一个 D3D 设备。这也是为什么必须复用 FFmpeg 内部 D3D 设备的原因。

多线程安全：如果 FFmpeg 解码线程和你的窗口 UI 渲染线程是分离的，在调用 StretchRect 和 Present 时需要注意多线程锁（例如 D3DCREATE_MULTITHREADED 标志），或者将 AVFrame 投递到渲染线程统一处理。

3. 色彩空间转换
IDirect3DDevice9::StretchRect 在大多数支持 DXVA2 的现代 GPU（如 Intel/NVIDIA/AMD）上，能够非常完美地直接将 NV12 表面拉伸并转换为 X8R8G8B8。但如果遇到极其老旧的显卡，可能会返回 D3DERR_INVALIDCALL。如果发生该错误，需要检查驱动或通过 Shader 处理转型。

使用示例
C++
// 初始化阶段
HWND hPlayWindow = GetDlgItem(hDlg, IDC_PLAYER_WINDOW); // 你的目标播放窗口
DXVA2WindowRenderer* renderer = new DXVA2WindowRenderer(pYourD3D9Device, hPlayWindow);

// 解码循环中
while (av_read_frame(pFormatCtx, pPacket) >= 0) {
    if (pPacket->stream_index == videoStreamIdx) {
        avcodec_send_packet(pCodecCtx, pPacket);
        while (avcodec_receive_frame(pCodecCtx, pFrame) >= 0) {
            // 渲染到指定窗口
            renderer->RenderFrame(pFrame);
            av_frame_unref(pFrame);
        }
    }
}
