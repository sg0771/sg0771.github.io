# CSP-J 2019 T4 的题目是 《加工零件》

## 这是一道关于图论和最短路径的综合应用题。

这道题的核心在于，需要回答轩轩（1号工人）是否需要提供原材料，本质上是在判断：从1号点到询问的a号点，是否存在一条长度≤L，且奇偶性与L相同的路径。

因为可以通过在一条边上来回走动“消耗”偶数步，所以只要有满足条件的较短路径，更长的同奇偶性步数都可以通过来回走动达成。

### 核心算法与思路

问题的关键在于，我们需要为每个点分别求出到达1号点的奇数长度最短路径和偶数长度最短路径。常用的高效求解方法是BFS（广度优先搜索）或SPFA。

一种很优雅的实现方式是“拆点”：把每个点拆成“奇点”和“偶点”两个状态，边的权值都为1，然后跑一遍BFS求最短路。具体步骤如下：

### 构建分层图：

将原图中的每个点 u 拆成两个节点：(u, 0) 代表到达 u 的路径长度为偶数，(u, 1) 代表路径长度为奇数。

对于原图中的一条无向边 u-v，在新图中添加四条有向边：(u,0) -> (v,1), (v,0) -> (u,1), (u,1) -> (v,0), (v,1) -> (u,0)。这表示每走一步，路径长度的奇偶性就会翻转。

### 执行BFS：

从起点 (1, 0) 开始（到1号点的偶数距离为0）进行BFS。

使用数组 dist[u][0/1] 记录到达 u 点的偶数/奇数最短路径长度。

### 回答问题：
对于每个询问 (a, L)，只需要检查 dist[a][L%2] 是否不大于 L。
若是，则输出 "Yes"；否则输出 "No"。
特别地，如果 a 号点是孤立的（没有任何边），那么除了 a=1 且 L=0（但数据中L≥1，所以不存在），其他情况都是 "No"。代码中可以通过检查是否存在邻接边来处理。

### 复杂度分析
时间复杂度：O(n + m + q)，主要花在BFS遍历图和回答每个询问上。
空间复杂度：O(n + m)，用于存储图和距离数组。

### 参考代码思路
以下代码逻辑基于搜索结果整理，展示了这种“奇偶最短路”的核心实现：

~~~cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
int n, m, q;
vector<int> edge[N];
int dist[N][2]; // dist[i][0]: 最短偶数路径, dist[i][1]: 最短奇数路径

void bfs() {
    memset(dist, 0x3f, sizeof(dist));
    queue<pair<int, int>> que;
    // 从 (1号点, 偶数状态) 开始，路径长度为0
    dist[1][0] = 0;
    que.push({1, 0});

    while (!que.empty()) {
        auto [u, parity] = que.front();
        que.pop();
        for (int v : edge[u]) {
            // 走到v点，奇偶性翻转
            int new_parity = parity ^ 1;
            if (dist[v][new_parity] > dist[u][parity] + 1) {
                dist[v][new_parity] = dist[u][parity] + 1;
                que.push({v, new_parity});
            }
        }
    }
}

int main() {
    scanf("%d %d %d", &n, &m, &q);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        edge[u].push_back(v);
        edge[v].push_back(u);
    }

    bfs();

    while (q--) {
        int a, L;
        scanf("%d %d", &a, &L);
        // 如果a是孤立点，除非a=1且L=0，否则走不到
        if (edge[a].empty() && !(a == 1 && L == 0)) { 
            printf("No\n");
            continue;
        }
        int need_parity = L % 2;
        if (dist[a][need_parity] <= L) {
            printf("Yes\n");
        } else {
            printf("No\n");
        }
    }
    return 0;
}
~~~
